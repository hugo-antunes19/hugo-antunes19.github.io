# Hugo Antunes — Portfólio

Site estático sobre Engenharia de Dados e Computação. HTML, CSS e JavaScript, sem dependências de build.

## Publicação

GitHub Pages: branch `main`, pasta `/(root)`, usando **Deploy from a branch** em **Settings → Pages**.
Endereço esperado: https://hugo-antunes19.github.io/

## Editar

- `index.html`: apresentação, projetos e metadados.
- `style.css`: cores e layout responsivo.
- `script.js`: links públicos e filtros. LinkedIn e e-mail ficam ocultos até serem informados.
- `.nojekyll`: publicação dos arquivos estáticos sem Jekyll.

As fontes do Google têm alternativas locais. As ilustrações são autorais e esquemáticas; não são capturas dos projetos.

## Prévia

Abra `index.html` no navegador ou execute `python -m http.server 4173 --bind 127.0.0.1` nesta pasta.

Documentação do Pages: https://docs.github.com/en/pages/quickstart
